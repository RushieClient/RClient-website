# Favicon set

Generated by favicongenerator.fyi

## Where to put each file

Default convention is to place the icons at these paths on your server:

    /favicon.ico
    /favicon.svg
    /icons/apple-touch-icon.png
    /icons/icon-192.png
    /icons/icon-512.png
    /icons/og-image.png
    /manifest.webmanifest

Then paste the contents of `snippet.html` inside the `<head>` of every
page on your site (or once in your shared layout/template).

## Adjusting paths

If you put the icons in a different folder, edit `snippet.html` and
`manifest.webmanifest` to match. The browser will fail silently if a
referenced file is missing — check your devtools Network tab if your
icon does not appear.

## Open Graph image

The 1200×630 og-image.png is referenced separately from your page
`<head>` only when you want to control how the URL appears when
shared on social platforms:

    <meta property="og:image" content="https://yoursite.com/icons/og-image.png">
    <meta property="og:image:width" content="1200">
    <meta property="og:image:height" content="630">
